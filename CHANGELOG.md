# История изменений

В этом файле собраны наиболее заметные изменения `bot-summary-vk` по всей
истории репозитория. Формальных версий и тегов пока нет, поэтому разделы
сгруппированы по датам коммитов, от новых к старым.

## Невыпущено

### Документация и сообщество

- Оформлен публичный контур проекта: MIT License, политика безопасности,
  руководство для участников, шаблоны Issue и Pull Request, а также правила
  ведения changelog.
- Документирован полный жизненный цикл данных беседы: хранение в PostgreSQL,
  передача внешним LLM и image-провайдерам, состав логов, ответственность
  оператора и процедуры удаления. README дополнен ссылками, badges и явным
  требованием выдавать сообществу права администратора беседы.

## Основные вехи

- Бот вырос из базового сборщика сообщений в устойчивую систему дайджестов с
  раздельным контекстом бесед, ручным и автоматическим запуском.
- Дайджесты учитывают предыдущие выпуски, ответы на сообщения и хронологию,
  что сохраняет связность обсуждения между пакетами.
- Добавлены изображения через OpenAI, Cloudflare и Yandex Art, автоматическая
  подготовка промпта, watermark и безопасный переход к тексту при сбое.
- Появились учет токенов, задержек и стоимости, статистика изображений,
  семидневный график и интерактивная диагностическая панель в VK.
- Усилена эксплуатационная надежность: идемпотентная публикация, сериализация
  миграций, управляемый lifecycle фоновых задач и устойчивый VK Long Poll.
- Контейнер запускается без root, PostgreSQL не публикуется наружу, а CI
  проверяет Go-код и сканирует исходники и образы на уязвимости.

## 2026-07-16 — качество и защита production-сборки

### Безопасность

- Обновлен application image: Go 1.26.5, Alpine 3.24.1 и актуальный `x/text`;
  приложение запускается от непривилегированного пользователя, добавлен
  healthcheck. (`ecdc5c2`)
- Production-образ PostgreSQL закреплен на версии 17.10 с исправлениями
  безопасности. (`8c63a32`)
- Добавлен GitHub Actions workflow с `gofmt`, тестами, `go vet`,
  `golangci-lint`, Trivy-сканированием исходников и application image, а также
  аудитом образа PostgreSQL. Обязательные локальные проверки зафиксированы в
  `AGENTS.md`. (`9631553`)

### Исправлено

- Устранены замечания линтера: результаты закрытия ресурсов и rollback теперь
  обрабатываются явно, удалены устаревшие и неиспользуемые проверки.
  (`054f1ad`)

## 2026-07-15 — интерактивная диагностика и надежность

### Добавлено

- Реализована генерация изображений через OpenAI и единая телеметрия
  image-провайдеров: модель, размеры, качество, количество изображений,
  задержка и оценка стоимости. (`1ffcf9a`)
- Добавлена поддержка callback-кнопок VK. Краткую статистику использования
  можно раскрывать и сворачивать без отправки новых сообщений; доступ к
  подробностям ограничен администраторами, для посторонних используются
  случайные ответы. (`d6bff68`, `29864ac`, `c5bd4ea`, `a13b46f`)
- Во время подготовки дайджеста бот публикует и обновляет анимированное
  progress-сообщение с редакционными фразами и индикатором Pac-Man, а после
  завершения удаляет его. (`727312f`, `1758cbd`)
- Добавлены публичные команды `пинг` → `ПОНГ` и пасхалка
  `заяц` → `ПЕТУХ`. (`e4faab7`, `3645d87`)

### Изменено

- Упрощен основной pipeline создания дайджеста и отдельно выделены обработка
  usage-статистики, расчет стоимости и запросы к хранилищу. Это уменьшило
  связанность крупных компонентов без изменения пользовательского сценария.
  (`cd1b34f`, `ff1ff1f`)
- Настроены качество OpenAI-изображений, внешний вид watermark, лимит ответа
  image-prompt LLM и пользовательские сообщения об ошибках. (`7d1fab8`,
  `74bf4af`, `efacff0`)
- Расширена документация по image-телеметрии, командам и runtime-настройкам.
  README сокращен до пользовательского руководства, архитектура и эксплуатация
  вынесены в `docs/`. (`84363a7`, `9ff2b98`, `1e555ed`)

### Исправлено

- VK Long Poll повторяет временно упавший обработчик update и после исчерпания
  попыток пропускает только проблемное событие, не останавливая весь цикл.
  (`6abde04`)
- Ручные и автоматические задачи дайджеста привязаны к lifecycle приложения:
  при shutdown новые задачи не принимаются, активные отменяются, а закрытие
  ждет их завершения. (`0dbf13b`)
- Миграции PostgreSQL сериализованы advisory lock, поэтому параллельный запуск
  нескольких экземпляров не выполняет DDL одновременно. (`da57189`)

## 2026-07-07 — безопасная публикация дайджестов

### Изменено

- Автоматические дайджесты вынесены из синхронной обработки входящих сообщений
  и сериализованы отдельно для каждой беседы. Повторный сигнал во время работы
  помечается как ожидающий и обрабатывается следующим проходом. (`03557a0`)
- Для диапазона сообщений рассчитывается стабильный VK `random_id`, что
  предотвращает дублирование выпуска при повторной отправке. Ошибки
  конфигурации возвращаются явно вместо panic, а при сбое изображения бот
  повторяет публикацию в текстовом виде. (`03557a0`)
- Добавлен workflow, который после push в `main` может публиковать список
  коммитов на стене сообщества VK; при отсутствии secret или variables шаг
  безопасно пропускается. (`0b289bf`)

## 2026-07-04 — изображения к дайджестам

### Добавлено

- Реализован image pipeline для Cloudflare и Yandex Art: отдельная LLM готовит
  промпт, изображение загружается в VK и прикрепляется к выпуску. Для каждой
  беседы ведется собственная нумерация выпусков. (`9283a2e`)
- На сгенерированные изображения накладывается полупрозрачный watermark `DDD`.
  (`ac9c37c`)

### Изменено

- Уточнено поведение генерации текста и обработка пустых или нестандартных
  ответов LLM. (`6a8a90d`)

### Безопасность

- Порт PostgreSQL удален из внешней публикации Docker Compose; база доступна
  только сервисам внутренней сети Compose. (`d2f8b61`)
